# Contributing guide

## Team workflow

Use the assigned roles:

- Person 1: ML model and project lead
- Person 2: Data cleaning, EDA, and graphs
- Person 3: Streamlit UI, report, and PPT

## Contribution rules

- Keep code readable.
- Document every major change in `docs/progress_log.md`.
- Do not commit secrets.
- Do not commit `.venv`.
- Do not claim final results until real dataset training is complete.
- Run tests before packaging.

## Code style

- Use clear function names.
- Keep model logic in `src/`.
- Keep dashboard logic in `app/`.
- Keep generated visuals in `visuals/`.
- Keep review materials in `reports/`.
