## Safe Copy Protection Approach

Recommended protection:

- Keep team names and roles in README/report/PPT.
- Keep a project manifest with project identity.
- Keep dated progress notes.
- Keep screenshots of development stages.
- Keep final model metrics and generated visuals.
- Keep a clear folder structure that shows process.

Avoid:

- Code obfuscation
- Hidden destructive checks
- Machine locking
- Secret tokens
- Anything that prevents faculty from reviewing the project
