# Deployment guide

## Local deployment

The recommended first deployment is local Streamlit.

```powershell
.\.venv\Scripts\streamlit.exe run app\streamlit_app.py
```

## Submission ZIP deployment

For college review, submit the release ZIP generated by:

```powershell
.\.venv\Scripts\python.exe scripts\create_release_zip.py
```

## Cloud deployment readiness

Before cloud deployment:

- Confirm dataset license allows redistribution or remote hosting.
- Add final trained model artifact.
- Add dashboard screenshots.
- Add `.streamlit/config.toml`.
- Do not commit secrets.
- Pin dependency versions if strict reproducibility is required.

## Streamlit Community Cloud notes

For Streamlit Community Cloud, the repository should contain:

- `requirements.txt`
- `app/streamlit_app.py`
- `src/`
- Required model/data artifacts or a documented download step

If the model or dataset is too large, use a documented external storage/download approach.
