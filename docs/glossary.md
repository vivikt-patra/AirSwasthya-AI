# Glossary

| Term | Meaning |
| --- | --- |
| AQI | Air Quality Index, a simplified scale representing air pollution level |
| PM2.5 | Fine particulate matter with diameter 2.5 micrometers or smaller |
| PM10 | Particulate matter with diameter 10 micrometers or smaller |
| NO2 | Nitrogen dioxide |
| SO2 | Sulfur dioxide |
| CO | Carbon monoxide |
| O3 | Ozone |
| EDA | Exploratory Data Analysis |
| MAE | Mean Absolute Error |
| RMSE | Root Mean Squared Error |
| R2 | Coefficient of determination |
| Lag feature | Previous-day value used as a model input |
| Rolling average | Average over a recent time window |
| Feature importance | Score showing which inputs influenced a model most |
