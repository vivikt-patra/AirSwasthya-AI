# Changelog — AirSwasthya AI

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-10-08

### Added
- **Next.js 16 App Router UI**: Next.js 16 dashboard with React 19, Tailwind CSS, Framer Motion 12, and React Three Fiber 3D canvas.
- **IQAir-Style Design**: Header bar with downward curve, dark overlay hover menus, and full-width edge-to-edge About Us / Impact section.
- **GIET Student Team Credits**: Complete team attribution for **Vivikt Patra**, **Soham Swain**, and **Mukul**.
- **Public Facilitation & Contact Tools**: Free data report requests, Open API documentation links, and email integration (`viviktpatra@gmail.com`, `sohamswain26@gmail.com`).
- **Statsmodels SARIMAX Integration**: 7-day ahead PM2.5 forecasting pipeline for Koraput, Nawarangpur, and Gunupur.

## 0.2.0 - 2026-08-03

- Added Streamlit dashboard review shell.
- Added EDA visual generation module.
- Added automated test suite (`pytest`).
- Added sample-data generator.
- Added release packaging script.
- Added architecture and workflow documentation.

## 0.1.0 - 2026-07-10

- Added data-cleaning pipeline.
- Added feature engineering module.
- Added CPCB AQI health advisory rules engine.
- Added model training and time-series prediction modules.
